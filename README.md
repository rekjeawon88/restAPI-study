# REST API Study Project

## 개발 환경
### IDE
- IntelliJ IDEA

### Project Setup
- Build Tool: Maven
- Language: Java 17
- Spring Boot: 3.4.5

### Dependencies
- Spring Boot Starter
- Spring Boot Starter Web
- Spring Boot Starter Test
- Lombok
- H2 Database
- Swagger (springdoc-openapi)

- JPA (Spring Data JPA)
